### 1.3 题型规律

- **国赛 A 题**：几乎年年是**连续机理建模**（物理/工程背景：热传导、流体、几何、控制），拼微分方程与参数标定功底
- **国赛 B 题**：**离散优化/调度/几何设计**，拼优化算法与问题转化能力
- **国赛 C 题**：**数据分析+决策**，拼数据处理、统计与机器学习，门槛低但区分度在深度
- **美赛 A/B**：机理/离散；**C**：数据（常附大型数据集）；**D**：运筹网络；**E**：环境；**F**：政策（最开放，写作权重最高）
- **趋势**：2019 后开放题、系统题增多——从"解题"转向"定义问题"，数据驱动与复杂系统建模成关键

## 2. 模范论文的通用结构（逐节拆解）

模范论文几乎都是同一个骨架，差别在执行质量。以国赛为例（美赛同构，另加 Summary Sheet）：

| 章节 | 篇幅占比 | 评委看什么 |
|---|---|---|
| 摘要 | 1 页内 | **问题-方法-结果三要素是否齐全**；这是生死线，评委先只读摘要 |
| 问题重述与分析 | ~5% | 是否真的"分析"了（分解子问题、指出关键矛盾），而不是复述题面 |
| 模型假设 | ~3% | 每条假设**为模型服务**且有依据；空泛假设是扣分点 |
| 符号说明 | ~2% | 全文符号统一，出现即定义 |
| 模型建立与求解 | ~60% | 按子问题分节；建模有推导、求解有过程、结果有数值表 |
| 模型检验/灵敏度分析 | ~15% | **获奖论文基本都有**：参数扰动、误差分析、与实际对比 |
| 优缺点与改进 | ~5% | 自我批判要具体，改进方向可落地 |
| 结论 | ~3% | 直接回答每个子问题，给出数值答案 |
| 参考文献 | 1 页内 | 少而精，正文有引用标号 |
| 附录 | 不限 | 完整可运行代码 + 补充图表 |

**美赛特有**：开头一页 Summary Sheet（相当于加强版摘要）+ Letter；页数上限内完整度优先。

## 3. 常用模型与算法清单（按题型备货）

### 3.1 评价/排序类
层次分析法（AHP）、TOPSIS、熵权法/CRITIC（客观赋权）、模糊综合评价、灰色关联分析、主成分分析（PCA）、数据包络分析（DEA）
> 组合套路：熵权法客观赋权 + TOPSIS 排序，是近十年 C 题类论文的高频组合。

### 3.2 优化类
线性/整数/非线性规划、多目标优化（加权/帕累托）、动态规划、贪心；启发式：遗传算法、模拟退火、粒子群、蚁群
> A/B 题主力；模范论文会交代算法参数、收敛性，并给灵敏度。

### 3.3 预测类
线性/Logistic 回归、灰色预测 GM(1,1)、ARIMA 时间序列、指数平滑；机器学习：随机森林、XGBoost、LSTM、神经网络
> 2018 年后机器学习占比明显上升；模范论文会做**多模型对比 + 误差指标**（MAE/RMSE/R²），并讨论过拟合。

### 3.4 分类/聚类类
K-means、层次聚类、DBSCAN、SVM、随机森林、高斯混合模型
> 会员画像（2018C）、玻璃鉴别（2022C）类题目的标准武器。

### 3.5 机理/动态类
微分方程组（SIR/SEIR 传染病、Logistic/Leslie 种群、热传导、动力学）、差分方程、元胞自动机、排队论、马尔可夫链、博弈论、图论（最短路、最大流、网络）
> 国赛 A 题与美赛 A 题的核心；SIR 及其变体是流行病/传播类题目的默认起点。

### 3.6 仿真类
蒙特卡洛模拟、多智能体仿真（ABM）、离散事件仿真
> 疏散、调度、随机环境类题目；模范论文用仿真弥补解析不可解，并用统计量报告不确定性。

### 3.7 数据分析基础
缺失值/异常值处理、特征工程、相关性分析、假设检验、降维、可视化
> **所有带数据的题目第一关**；数据预处理的严谨程度直接决定可信度。

## 4. 评审视角：评委到底看什么

### 4.1 国赛评审四维度
1. **模型假设的合理性**
2. **建模的创造性与实用性**（权重最高）
3. **求解的正确性**（结果数值可信）
4. **表达的清晰性**（写作与规范）

### 4.2 美赛评审取向
清晰度（Clarity）、有效性（Validity）、可行性（Feasibility）、假设的合理性、灵敏度与稳健性；摘要（Summary Sheet）是初筛的第一依据。

### 4.3 评委最反感的三类论文（反面教材）
1. **摘要堆空话**：术语流水账、无核心成果、缺数值结论
2. **图表潦草**：Excel 默认配色、模糊截图、无标题无单位、坐标轴不标注
3. **格式混乱**：公式样式不一、编号跳号、符号不统一、引用格式混搭

## 5. 模范论文的七个共同特征（O 奖/国一经验合成）

1. **摘要决定生死**：一页内讲清"解决什么问题、用什么方法、得到什么结果（带关键数值）"，逻辑闭环、零错别字；评委时间极有限，摘要不过关全文白写。
2. **模型"简单而完整"**：评审反复强调——**贴合题目的简单完整模型，优于炫技的复杂模型**。复杂只在必要时引入，且要说明为什么。
3. **灵敏度分析是标配**：对关键参数做扰动，讨论结果稳健性；这是"模范"与"普通"的分水岭。
4. **可视化有审美**：图表自明（标题、单位、图例齐全），配色统一，关键结论"看图即得"。
5. **数据处理严谨**：来源说明、清洗过程、异常值处理有记录；不回避数据缺陷，反而在假设中声明。
6. **假设不写空话**：每条假设要么简化问题、要么界定适用范围，与后文模型一一对应。
7. **完整性**：每个子问题都有明确回答；不遗漏、不含糊；代码附录可运行。

**团队分工经验**（O 奖队伍共识）：建模、编程、写作三角色分工明确并提前演练；写作不是最后才介入，而是全程同步。

## 6. 十年演化趋势（2015 → 2025）

| 维度 | 十年前 | 现在 |
|---|---|---|
| 题目形态 | 条件较完备、目标明确 | 开放题增多，要自己"定义问题"（美赛 F 类、国赛 C 题决策类） |
| 数据角色 | 数据为辅 | 数据驱动成主流，常附大型真实数据集 |
| 建模方式 | 单一模型打天下 | 模块化组合：机理+数据混合建模、模型对比与融合 |
| 方法热度 | 评价三板斧（AHP/灰色/模糊）为王 | 机器学习占比大幅上升；但评委同时开始关注**可解释性**与过拟合 |
| 验证要求 | 有结果即可 | 灵敏度/稳健性检验接近"硬性"要求 |
| 呈现标准 | Word 手写公式常见 | LaTeX + 专业绘图库（matplotlib/plotly/ECharts）是模范论文标配 |
