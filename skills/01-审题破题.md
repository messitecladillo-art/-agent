# Skill 01 · 审题破题（阶段 0：问题分析）

> 本 skill 是比赛第一环。目标：**在 60 分钟内把赛题转化为可执行的子问题清单与评审重点预判**。
> 事实基础：官方评阅总则与 2021–2024 各题评阅要点（资料包 `01_国赛资料模块/官方评阅标准/`）、
> `notes/exemplary-paper-breakdown.md` §1/§4。

## 输入 / 输出

| 输入 | 输出 | 落点 |
|---|---|---|
| 赛题原文 + 全部附件 | 审题报告（模板见 §6） | `notes/problem-analysis.md` |
| 队伍人数与时间盒 | 选题决定（国赛可多选一） | 同上，附理由 |

## 步骤

### 1. 全文精读（20 分钟，不许提前建模）
- 逐句标注：**任务动词**（确定/分析/给出/预测/评价/优化/设计/讨论）、**显式约束**、**附件清单**
- 识别"隐藏要求"：题目注释（"注："段落往往是评阅要点的预告，如 2024 C 注"本题不是纯数据分析题"）
- 美赛：先读 Context 与 Background，圈出必须回答的明确问句（通常 3–5 个）

### 2. 题型判定（决定后续全部打法）

**国赛（CUMCM）**

| 信号 | 判定 | 官方评审预期（据此定打法） |
|---|---|---|
| 物理/工程背景、微分方程/几何/控制 | A：连续机理 | 评阅要点常附**参考数值**，结果必须能对表；约束要**逐条验证**；结论要"**用数值论证，而非仅仅算出**"（2024 A 原文） |
| 调度/排班/设计/抽样/决策 + 离散结构 | B：离散优化/统计 | 关键概念必须**先定义再使用**（2023 B 覆盖率、2024 B 判据）；**不得默认正态性**（2024 B 原文） |
| 附数据集 + 定价/补货/分类/信贷 | C：数据决策 | "**不是纯数据分析题**"（2024 C 注）；简单统计+可视化 ≠ 好论文（2023 E 注）；要有模型与不确定性分析 |
| 专科/拓展（D/E） | 按上述信号细分 | 估计题给**置信区间**；算法讨论全局最优性；**模型优先于算法**（2021 D）；在线优化**禁用未来信息** |

**美赛（MCM/ICM）**：A 连续 / B 离散 / C 数据（附大数据库）/ D 运筹网络 / E 环境 / F 政策（写作权重最高）

### 3. 子问题拆解
- 每个子问题一行：**类型**（分析/建模/求解/决策）→ **依赖**（哪问的结果喂哪问）→ **候选模型方向**（交给 Skill 02）
- 官方评阅要点按"第 1 问/第 2 问…"组织，**子问题编号必须与题面严格对齐**，评审时逐问找答案

### 4. 数据盘点（有数据必做）
清单：规模 / 字段 / 时间粒度 / 缺失与异常 / 来源可信度。
评审信号（2023 C 官方要点原文提炼）：
- 异常数据怎么处理（缺货、退货、零销量）是**必答题**
- 要考虑时间效应（季节性、节假日、趋势）
- 相关分析要用**合适的方法**，不是只会算相关系数

### 5. 评阅重点预判（直接抄官方思路）
- 找当年评阅要点（若有）或近三年同题型要点，**把评委的"应重点考虑"逐条抄进审题报告**，变成自己的得分清单
- 预判参考数值量级（A 题）；预判需要自定义的量（B/C 题）；预判风险-收益权衡点（决策题）

### 6. 输出模板（审题报告骨架）

```markdown
# 审题报告：<年份><题号> <题名>
## 1. 题型判定与理由
## 2. 子问题清单（编号对齐题面）
| # | 类型 | 依赖 | 候选方向 | 预计工作量 |
## 3. 数据盘点（含异常处理预案）
## 4. 官方评审预期（逐条，来源标注）
## 5. 需自定义的量（定义→论证→使用 三步走清单）
## 6. 风险清单与初步假设
## 7. 选题结论（若多选一）与理由
```

## 常见错误（反面教材）
1. **跳过审题直接建模**——任务动词看错（把"分析"做成"预测"）全篇偏题
2. **误判题型**——把 C 题当纯数据分析做，官方明确压低
3. **忽略"注"段**——官方注释几乎就是明牌评分点
4. **假设先行**——先写了十条通用假设再看题，违反"假设为模型服务"（breakdown §2）
