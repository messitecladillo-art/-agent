# Skill 08 · 美赛专项（MCM/ICM 特有打法）

> 国赛骨架见 Skill 05；本 skill 只写美赛**增量**：摘要初筛制、Letter、Strengths & Weaknesses、英文规范。
> 事实基础：资料包 `09_数学建模与编程参考书库模块/美赛讲解与论文写作/`（题解析第 1–7 辑、《正确写作美国大学生数学建模竞赛论文》）与 `02_美赛资料模块/`，2026-08-31 精读蒸馏。

## 1. 评审体制（决定策略）

- **奖项分布**：S ≈50–60%（写得合理即得）；H ≈28–30%；M ≈10–15%；F ≈1%；**O <1%**（2012 年 3697 队仅 10 个 O）
- **初筛（triage）**：每篇约 10 分钟、2 名评委，分歧加第 3 人——**Summary Sheet 直接决定过线**
- **评委七条标准**（《正确写作》）：问题解释合理；假设清晰且有论证；分析足以支撑方法选择；模型有效解决问题；稳定性/敏感性检验；优缺点与结果讨论；摘要令人满意
- **关键文化**：不完整但有独创性的解法仍可获好评；美方评委比中方评委更重**创意与创新**
- **O 奖充分条件**（官方 Judge's Commentary）：回答所有子问题 + 包含全部要求产出物 + 有某种模型验证；共性是至少一个问题被分析得极透彻、建议明确且在情境中得到论证
- 专项奖：INFORMS / SIAM / MAA（各题择一 O 奖）、Ben Fusaro（有创意但有缺陷）、Giordano（离散建模最佳）

## 2. Summary Sheet（生死线，独立 1 页置顶）

- **长度**：半页到 2/3 页，绝不超过一页
- **必备要素**：用自己的话复述问题；关键假设及理由、主要变量；模型设计与选型理由；检验与敏感性结果；优缺点；**关键数值结果**
- **写法**：从头写、多遍修改；第一句要抓人（忌 "First we… then we…" 流水账）；尽量给数字、尽量不写公式；**忌罗列一长串技术名词淹没结果**
- **初筛评委雷区**：表头用难懂希腊字母/缩写；定义埋在大段正文里（应用项目符号）；公式变量未定义；整段照抄教材推导（应引用并说明会用即可）

## 3. 美赛特有产出物与结构

1. **Letter/Memo（1 页，必交，计入评审）**：写给题面指定的非专业对象（期刊编辑/管理者/杂志），用白话讲清结论与建议
2. **官方推荐七段结构**：问题重述/澄清 → 假设与论证 → 方法分析论证 → 模型设计 → 检验方案（误差/稳定/敏感）→ **Strengths and Weaknesses（独立章节）** → Summary
3. 补充要素：明确的结论、进一步探索建议、完整参考文献——**引用不标注可致取消资格**
4. 建议加目录；假设用项目符号逐条列出并逐条论证；论文超 80 页必删减（评委每篇仅 5–30 分钟）
5. 提交：PDF；页数上限以当年题目规定（20 或 25 页）；官方只给摘要页模板，正文框架自由

## 4. 分题型打法

| 题 | 主流打法 | 注意 |
|---|---|---|
| A 连续 | 物理机制建模（热传导/力学/微分方程） | 给 "best/optimization" 等模糊词以精确数学定义；对所用数据的仔细讨论是答案的一部分 |
| B 离散 | 仿真 + 组合优化（随机模型、元胞自动机、排队论、图论、调度） | 仿真必须跑足够次数才有统计意义；附伪代码；参数全部定义 |
| C 数据 | 领域知识 + 数据（排队+微分方程+图论等混合） | 套路：先选度量指标 → 建网络/动力系统模型 → 验证与敏感性 → 识别关键节点/临界点 |
| D 运筹/网络 | 静态网络结构 + 行为模型（贝叶斯学习、AHP）+ 多代理人动态仿真 | 可做多层网络拓展 |
| E 环境 | 先**定义"可持续性"并构建指标体系**，再定量化目标与多年计划，单一国家案例，最后检验与敏感性 | 指标体系本身就是模型 |
| F 政策 | 伦理与政策单独成节；多方法并列比较后评价；写作权重最高 | 资料包中第 7 辑 F 题章节扫描缺失，待补 |

## 5. 英文写作规范

**风格八条**：第一人称复数 we；现在时为主；主动语态；短句短段；用词具体（equation 不写 expression）；删琐碎细节；关键句加粗前置；**不夸大结果、不用感叹号**

**高频语法错误**：主谓一致（"One of the solutions is…"）；that/which 区分；美式拼写 + 拼写检查；正式文体不用缩写（cannot 而非 can not）；冠词（a norm / an hour 按发音）

**符号规范**：标题不用数学符号；不用符号开头的句子；同一符号全文读法一致；避免一符多用与多余下标；公式断行对齐

**数学叙述**：每个 if 配 then；术语在即将使用时定义；文字叙述为主、公式为辅（avoid excessive equations）

**修改清单**：被动改主动、繁词改简词、长句拆短句、每条假设是否已论证、信息顺序是否合逻辑、引用是否全部标注；先精修 Summary 再通读全文

## 6. 美赛时间盒（相对国赛的调整）

- 拿题日：每人**单独翻译**再合议定稿（避免先入为主）
- 优化模型须占论文约三分之一篇幅
- 截止前晚 8 点前完成：模型优化 + 灵敏度分析 + 初稿
- 交卷前把电脑时间调为**美东时间**；报名系统 first name=名、last name=姓
- 赛中禁止与队外讨论（官方监控论坛与群）
