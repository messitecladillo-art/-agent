# Skill 05 · 论文写作（阶段 4：写作）

> 目标：把前三阶段的成果写成评委 6 分钟内能看懂、能对表的论文（2010B 评卷实测约 6 分钟/份）。
> 生死线：**摘要决定生死**——摘要约占总评分 30–45%；2010B 细则 = 摘要 10 分 + 正文 80 分 + 总体印象 10 分，红字警示"大多评委基本以摘要定全文，先按摘要分档次再评阅"。
> 总则警示：官方点名反对"**模板化、形式化、虚拟化**"，每节必须回答本题特有的问题。

## 输入 / 输出

| 输入 | 输出 | 落点 |
|---|---|---|
| 各阶段产出 | 完整论文（模板 + 图表） | `paper/`（图入 `paper/figures/`） |

## 1. 国赛格式硬规范（违反任何一条都是合规事故）

1. **页面**：A4，四边距 2.5cm；正文横排
2. **页序**：第 1 页 = 承诺书（只写报名号 + 签名）；第 2 页 = 赛区评阅标注页（留空，不写任何内容）；第 3 页 = 题目 + 摘要，第 4 页起正文
3. **匿名**：无页眉页脚装饰，全文任何位置不得出现姓名 / 学校 / 导师等身份标志
4. **页码**：自第 3 页起，页脚居中阿拉伯数字从 1 连续编
5. **字体**：题目 3 号黑体；一级标题 4 号黑体居中；正文小 4 宋体、单倍行距、首行缩进 2 字符；中文宋体 / 英文 Times New Roman；公式变量逐一解释，重要公式右侧编号
6. **打印**：避免彩色打印（彩图黑白打印成灰块）；图线粗与对比度按灰度可辨设计
7. **篇幅**：正文 ≤15 页为佳（2010B 细则明示）；排版紧凑不留空行空白区；**超 25 页才加目录**（不含封面摘要参考文献），否则不加目录
8. **参考文献著录**：按引用次序列出；书籍须注页码；书 / 期刊 / 网络资源三种格式统一不混搭

## 2. 标准骨架与篇幅配比（国赛；美赛骨架见 Skill 08）

标题可用"基于 XX 模型的 XX 问题研究"套路。官方只规定页面格式与承诺书/编号页，不规定章节骨架——模板仅搭结构，内容必须本题化。

| 章节 | 占比 | 评委看什么 | 写作要点 |
|---|---|---|---|
| 摘要 | 1 页内 | 问题-方法-结果三要素是否齐全 | **最后写、最精修**；见 §3 配方 |
| 问题重述 | ~2% | 是否自己消化了题面 | 原题**改写**半页~一页，**严禁原样复制**（查重）；只复述/复制背景 = 很差 |
| 问题分析 | ~3% | 是否真"分析"了 | **每小问一份**；分解子问题、指出关键矛盾；**不写求解结果**，可后补 |
| 模型假设 | ~3% | 每条假设为模型服务且有依据 | 只写三类：①忽略次要因素 ②变量设为常数（**须配灵敏度分析**）③小概率事件不发生；须有事实依据——过繁难求解、过简无指导意义；与 Skill 02 决策记录对应 |
| 符号说明 | ~2% | 全文统一，出现即定义 | 一张表管到底，只列常用变量 |
| 模型建立与求解 | ~60% | 按子问题分节，编号对齐题面 | 小问用二级标题、模型大步用三级标题；基本模型须完整正确，简化要说明；**实用优先**（初等方法、让更多人看懂）；结果分析必须逐条列数值并**把数学结果转化为赛题所问的答案** |
| 模型检验/灵敏度 | ~15% | 获奖论文基本都有；不检验则"评委不相信你的自信" | 直接引用 Skill 04 四件套结论；灵敏度只适合预测/最优化类，先完成建模求解再做 |
| 优缺点与改进 | ~5% | 自我批判要具体 | "优点突出、缺点避重就轻"但不回避；改进可落地，不玩弄新术语，不写"有待提高"式空话 |
| 结论 | ~3% | 直接回答每个子问题 | 全文概括 + 每个子问题一个明确数值答案 + 不足之处客观评估；**不得写"希望评委老师…"** |
| 参考文献 | 1 页内 | 少而精 | 在使用处标 [x]；正文引用了才列 |
| 附录 | 不限 | 完整可运行代码 | **严禁直接复制网上代码**（有取消获奖并通报的先例）；须改变量名；错的代码宁可不列；清空环境重跑验证过 |

## 3. 摘要配方（占总评分 30–45%，两轮评审均先筛摘要）

```
长度：200–300 字（国赛）
结构：开头段（4–6 行：问题 + 总体模型）
     + 每小问一段（用了什么模型、关键参数取值、求解过程与结果、结果意义）
     + 结尾段（方法特色与验证手段：灵敏度/对表/互验）
关键词：4–8 个（模型名 + 算法名 + 问题域），须与摘要同页
```
写作工艺（经验谈共识）：**花 3 小时以上改十几稿**；一人起草、另两人评审；写参数取值理由以证明真懂模型；结果少则写数值、多则指向图表。
自查：遮住正文只看摘要，能否回答每个子问题？有没有至少 3 个具体数值？

## 4. 图表规范（评委最反感第二类：图表潦草）

1. 每图每表必有：**编号、标题、单位、图例**；坐标轴全部标注
2. **三线表**：表题在上、图题在下；数值对齐小数位；大表进附录、正文放摘要表
3. 标题层级不超过三级；图必须自己画，**不得截图参考资料**
4. 配色全文统一（Antigravity 出规范放 `viz/`）；拒绝 Excel 默认配色与模糊截图；灰度打印可辨
5. 关键结论"看图即得"：结论直接标在图上（如最优点、拐点）
6. 制图工具优先级：Python matplotlib/plotly > MATLAB > Excel
7. 数值对表：摘要、正文、表格、图里的同一结果必须完全一致（评委抽查高频点）

## 5. 行文铁律

1. **反模板腔**：每一节开头回答"本题这一步为什么要做、解决了什么"，删掉"随着社会发展……"式万能开头
2. **符号全文统一**：同一量不许中途换记号；公式编号连续不跳号
3. **数值一致性**：摘要、正文、表格、图里的同一结果必须完全一致（评委抽查高频点）
4. **引用规范**：格式统一，不堆砌；注明出处即非抄袭，但整篇引用 = 抄袭
5. **页数合规**：国赛正文 ≤15 页为佳 + 承诺书；美赛按当年页数上限（20 或 25 页），完整度优先
6. **防丢稿**：Word 公式多易死机，勤按 Ctrl+S（有作者两次全文丢失的先例）；建议 git 每 2 小时提交一版

## 6. 写作节奏（写作全程同步，不是最后才介入）

- 阶段 0–2 期间：Qoder 同步写"问题分析、假设、符号、模型框架"骨架（占全文 ~30%，且不受求解进度影响）
- 阶段 3 完成：填数值与图表；截止前晚 8 点前须完成模型优化 + 灵敏度 + 初稿
- 提交前 6 小时：**冻结模型**，全部时间给摘要精修 + 一致性校对 + 格式；摘要随初稿逐步完善
- 分工：Qoder 主笔；Antigravity 出图到 `paper/figures/`；Codex 整理附录代码；论文一人主编统稿，行文避免个人色彩

## 7. 常见错误

1. **摘要堆空话**：术语流水账、无核心成果、缺数值结论（评委最反感第一类）
2. **格式混乱**：公式样式不一、编号跳号、符号不统一、引用格式混搭（最反感第三类）
3. **重述凑字数**：问题重述复制题面，官方总则明确压低
4. **结论含糊**：子问题没有明确数值答案，"有一定效果"式结论
5. **附录抄网上代码**：一票否决项，已有取消获奖并通报先例
6. **数学结果不翻译**：只给公式解、不回答赛题实际所问
