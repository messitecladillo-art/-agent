# Skill 05 · 论文写作（阶段 4：写作）

> 目标：把前四阶段的成果写成评委 10 分钟内能看懂、能对表的论文。
> 生死线：**摘要决定生死**——评委时间极有限，先只读摘要（breakdown §5-1）。
> 总则警示：官方点名反对"**模板化、形式化、虚拟化**"，每节必须回答本题特有的问题。

## 输入 / 输出

| 输入 | 输出 | 落点 |
|---|---|---|
| 各阶段产出 | 完整论文（模板 + 图表） | `paper/`（图入 `paper/figures/`） |

## 1. 标准骨架与篇幅配比（国赛；美赛同构，另加 Summary Sheet）

| 章节 | 占比 | 评委看什么 | 写作要点 |
|---|---|---|---|
| 摘要 | 1 页内 | 问题-方法-结果三要素是否齐全 | **最后写、最精修**；每个子问题一句方法+关键数值；零错别字 |
| 问题重述与分析 | ~5% | 是否真"分析"了 | 分解子问题、指出关键矛盾；**禁止复述题面** |
| 模型假设 | ~3% | 每条假设为模型服务且有依据 | 与 Skill 02 决策记录一一对应；删掉零信息假设 |
| 符号说明 | ~2% | 全文统一，出现即定义 | 一张表管到底 |
| 模型建立与求解 | ~60% | 按子问题分节，编号对齐题面 | 建模有推导、求解有过程、结果有数值表 |
| 模型检验/灵敏度 | ~15% | 获奖论文基本都有 | 直接引用 Skill 04 四件套结论 |
| 优缺点与改进 | ~5% | 自我批判要具体 | 改进方向可落地，不写"有待提高"式空话 |
| 结论 | ~3% | 直接回答每个子问题 | 每个子问题一个明确数值答案 |
| 参考文献 | 1 页内 | 少而精 | 正文有引用标号 |
| 附录 | 不限 | 完整可运行代码 | 清空环境重跑验证过 |

**美赛特有**：首页 Summary Sheet 是初筛第一依据（加强版摘要 + 结论速览）；评审取向 = 清晰度 / 有效性 / 可行性 / 假设合理性 / 灵敏度与稳健性。

## 2. 摘要配方（国赛生死线）

```
第一段：问题背景一句话 + 逐子问题给出"用了什么模型/方法，得到什么结果（关键数值）"
第二段：方法特色与验证手段（灵敏度/对表/互验）一句话
关键词：4–6 个（模型名 + 算法名 + 问题域）
```
自查：遮住正文只看摘要，能否回答每个子问题？有没有至少 3 个具体数值？

## 3. 图表规范（评委最反感第二类：图表潦草）

1. 每图每表必有：**编号、标题、单位、图例**；坐标轴全部标注
2. 配色全文统一（Antigravity 出规范放 `viz/`）；拒绝 Excel 默认配色与模糊截图
3. 关键结论"看图即得"：结论直接标在图上（如最优点、拐点）
4. 表格：三线表；数值对齐小数位；大表进附录、正文放摘要表
5. 制图工具优先级：Python matplotlib/plotly > MATLAB > Excel（模范论文标配是专业绘图库）

## 4. 行文铁律

1. **反模板腔**：每一节开头回答"本题这一步为什么要做、解决了什么"，删掉"随着社会发展……"式万能开头
2. **符号全文统一**：同一量不许中途换记号；公式编号连续不跳号
3. **数值一致性**：摘要、正文、表格、图里的同一结果必须完全一致（评委抽查高频点）
4. **引用规范**：格式统一，不堆砌；引用了就要在正文用
5. **页数合规**：国赛正文页数限制 + 承诺书；美赛按当年页数上限，完整度优先

## 5. 写作节奏（写作全程同步，不是最后才介入）

- 阶段 0–2 期间：Qoder 同步写"问题分析、假设、符号、模型框架"骨架（占全文 ~30%，且不受求解进度影响）
- 阶段 3 完成：填数值与图表
- 提交前 6 小时：**冻结模型**，全部时间给摘要精修 + 一致性校对 + 格式
- 分工：Qoder 主笔；Antigravity 出图到 `paper/figures/`；Codex 整理附录代码

## 6. 常见错误
1. **摘要堆空话**：术语流水账、无核心成果、缺数值结论（评委最反感第一类）
2. **格式混乱**：公式样式不一、编号跳号、符号不统一、引用格式混搭（最反感第三类）
3. **重述凑字数**：问题重述复制题面，官方总则明确压低
4. **结论含糊**：子问题没有明确数值答案，"有一定效果"式结论
