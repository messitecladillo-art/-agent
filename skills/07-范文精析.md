# Skill 07 · 范文精析（辅助能力：把获奖论文变成教材）

> 目标：把一篇获奖论文拆解成可模仿的结构化笔记，反哺备赛。
> 用途：赛前精读（近五年优先）、赛后复盘对照、给 review.py 提供"好论文长什么样"的参照。

## 输入 / 输出

| 输入 | 输出 | 落点 |
|---|---|---|
| 一篇获奖论文（PDF） | 精析笔记（模板见 §3） | `notes/paper-notes/<年份>-<题号>-<编号>.md` |

## 1. 精读优先序（资料包使用策略）

1. 近五年 > 更早（题型风格 2019 后明显转向开放/数据驱动）
2. 每年选 **1 篇 A 题 + 1 篇 C 题**（覆盖机理与数据两大主线），B 题按当年备赛方向补
3. 命名如 `A092.pdf` = A 题 92 号论文；同题多篇对比着读更有价值
4. 配 `资料包/01/获奖论文_按模型算法/`：精析某篇时，顺手找同类算法的另 1 篇对照写法差异

## 2. 拆解维度（对照 breakdown §2 骨架逐项提取）

1. **摘要配方**：数一数用了几句话、给了几个数值、方法名怎么报
2. **问题转化**：原题被拆成哪几个子问题？与题面编号如何对齐？
3. **模型链**：按顺序列出"模型 → 解决什么 → 输入输出"，标出创新点所在环
4. **数据处理**：异常值/缺失怎么处理、声明了哪些数据假设
5. **验证与灵敏度**：扰了哪些参数、用什么图呈现、结论稳健性怎么说的
6. **图表配置**：每张图的类型、信息密度、结论是否"看图即得"
7. **篇幅分配**：实测各章占比，与标准骨架（写作 Skill §1）对比
8. **可偷的招**：定义方式、验证技巧、表达句式——具体到能复用

## 3. 精析笔记模板

```markdown
# 精析：<年份> <题号> <论文编号>（奖项：<国一/国二/…>）
## 0. 一句话评价
## 1. 摘要配方拆解
## 2. 子问题拆解方式
## 3. 模型链（图或列表）
## 4. 数据处理与假设
## 5. 验证与灵敏度做法
## 6. 图表清单与亮点
## 7. 篇幅实测
## 8. 可偷的招（≥3 条，具体）
## 9. 它的短板（若按 Skill 06 rubric 审，会扣在哪）
```

第 9 项是刻意练习：用评审 rubric 审获奖论文，校准自己对"好"与"更好"的分辨力。

## 4. 批量模式（Claude API 初筛）

- 大批量粗读：用 `scripts/agents/` 扩展脚本 + Claude API 对每篇生成第 0/3 节速览，人工再精读值得深拆的
- 注意：精析结论必须落盘（笔记文件），对话里的口头结论无效

## 资料锚点
- 按年份：`资料包/01_国赛资料模块/历年赛题与获奖论文_按年份/`（2013–2024，145 篇）
- 按算法：`资料包/01/获奖论文_按模型算法/`（35 类）
- 官方点评：`资料包/01/赛题解析/获奖论文精选与点评（第二卷）`
- 美赛：`资料包/02_美赛资料模块/` 英文获奖论文 + 配套代码

## 衔接
精析发现的好做法 → 更新对应 skill（写作招式进 05、验证招式进 04）；发现的新评审信号 → 更新 06 的 rubric。
