# 方法路由矩阵

方法卡是候选工具，不是关键词命中器。路由顺序固定为：题面结构 → 数据/机理
证据 → 透明基线 → 主模型 → 备用模型 → 验证门。

## 1. 结构到候选族

| 结构证据 | 首个可解释基线 | 可升级主模型 | 必须回答的风险 |
|---|---|---|---|
| 连续状态、守恒、边界/初值 | 平衡或低阶 ODE | PDE、有限元、系统动力学 | 边界、稳定性、守恒、网格/步长 |
| 线性资源约束和单目标 | LP | MILP、鲁棒、多目标 | 可行性、整数语义、最优性 gap |
| 阶段决策与状态转移 | 枚举/贪心 | DP、MILP、局部搜索 | 最优子结构、状态爆炸、边界值 |
| 组合空间且精确法成本高 | 可行贪心 | GA/SA/PSO/蚁群/局部搜索 | 基线 gap、重复种子、约束修复 |
| 时间序列 | 朴素/季节朴素 | ARIMA、状态空间、树模型 | 时间顺序、滚动回测、漂移 |
| 连续响应 | 均值/线性回归 | 岭/GLM/树模型 | 残差、外推、共线、分布 |
| 二分类/排序 | 多数类/逻辑回归 | RF、SVM、提升树 | 类别不平衡、校准、特征泄漏 |
| 无标签分群 | 规则/分层描述 | K-means、DBSCAN、GMM | 距离尺度、簇数、稳定性 |
| 不确定性传播 | 情景表 | Monte Carlo/LHS | 分布来源、重复数、区间 |
| 流程、到达、服务、资源竞争 | 解析排队近似 | 离散事件/排队网络仿真 | 暖机、重复、容量、队列守恒 |
| 多指标评价 | 单指标排序 | AHP/TOPSIS/熵权/PCA | 权重依据、量纲、稳健性 |

## 2. 七件套选择记录

每次选主模型都填写：

1. 题面结构证据（原句和附件字段）；
2. baseline 及其失败/不足；
3. primary 为什么补足不足；
4. 假设与适用域；
5. 禁用条件和 fallback 触发器；
6. 需要的验证和最低通过阈值；
7. 结果如何翻译成题目要求的决策/解释。

## 3. 反套用规则

- 只因资料目录中某算法论文数量多，不得提升其优先级。
- 没有定义目标、变量、约束和数据生成机制，不得进入求解。
- 预测模型不能自动回答因果问题；特征重要性不能写成因果效应。
- 启发式解不能称全局最优，除非有理论界或小规模精确对照。
- 评价组合不能用权重掩盖冲突；至少报告权重/标准化敏感性。
- 复杂模型若没有相对基线的可量化增益，回退到简单模型。
