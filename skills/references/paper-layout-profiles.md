# 论文排版与交付 profile

## 1. Profile 选择

| profile | 适用条件 | 必须先确认 | 结构提示 |
|---|---|---|---|
| cumcm-current | 当前高教社杯国赛 | 当届通知、匿名/页数/格式 | 摘要、问题分析、假设、符号、分问建模求解、检验、优缺点、结论、参考文献、附录 |
| national-template-convention | 只有资料包 Word 模板 | 说明为“常见模板” | 可借鉴骨架，不得宣称官方 |
| mcm-current | 当前 MCM/ICM | 当届规则、题目、文件命名/截止 | Summary Sheet、正文、Letter/Memo、Strengths & Weaknesses |
| other-contest-pending | 其他赛事 | 官方格式文件 | 只生成草稿，格式门为 OFFICIAL_PENDING |

## 2. 数学表达门

- 符号首次出现即定义；同一符号不得跨语义复用。
- 重要公式编号，编号按章节或全文连续且交叉引用可解析。
- 从定义、假设到方程，再到离散/算法和结果，不能只展示求解器调用。
- 量纲、上下标、向量/矩阵和函数字体统一；数值带单位和有效位说明。
- 每张表有上方标题、字段/单位和来源；每幅图有下方图注、坐标/图例/单位。
- 三线表优先；截图和低分辨率默认拒绝。

## 3. 版面与 PDF 门

- 层级通常不超过三级，除非当前官方模板要求更多；
- 中文字体、英文字体、公式字体分别登记实际资源和许可证；
- 目录、引用、图表编号、页码和书签在最终 PDF 中可追踪；
- 编译日志无 error，引用/字体缺失警告有处置记录；
- 对最终 PDF 做 pdfinfo、文本抽取、哈希和全页渲染 QA；
- 版式通过不等于数学正确；必须同时通过模型和证据门。

## 4. 摘要检查

摘要先回答问题，再按小问给方法、关键数字/区间和结论；不在摘要中承诺
尚未 VERIFIED 的结果。摘要通常最后写，但应在中期用占位字段检查覆盖。
