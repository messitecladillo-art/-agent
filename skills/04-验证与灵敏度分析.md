> 灵敏度分析是"模范"与"普通"的分水岭（breakdown §5-3），近十年获奖论文基本都有。

| 输入 | 输出 | 落点 |

## 1. 验证四件套（每篇论文必须齐）

### ① 灵敏度分析（硬性：≥2 个关键参数）
- 单参数扰动：±10%/±20%（或按参数物理意义定范围），观察关键输出变化率
- 联合扰动至少做一组（2023 D："讨论偏离合理范围对结果的影响"）
- **必须讨论**：结论是否翻转？若不翻转 → 写"结果稳健"；若翻转 → 诚实写出边界条件（这是加分而非减分）
- 产出形式：龙卷风图/热力图 + 一张"参数—扰动—结论变化"表

### ② 有效性检验（模型对不对）
- 与实际对比：有真实观测就对比观测；没有就用**特例/极限情形**检验（参数取极端值，模型行为是否符合物理直觉）
- 自洽关系核验：找守恒量或恒等式（范例：2023 A 官方验法 DNI×光学效率≈单位面积输出热功率）
- 与备选模型互验：主模型与备选模型在同一子问题上结论是否一致（不一致 → 分析原因，往往是深度亮点）

### ③ 误差与不确定性分析
- 回归/预测类：报 MAE / RMSE / R²，**讨论过拟合**（训练/测试划分或交叉验证）
- 估计类：**给置信区间**（2023 D 官方硬性要求），并讨论区间外的影响
- 仿真类：报样本量、重复次数、结果的统计显著性（2023 D 问题 3 原文要求）

### ④ 约束与可行性复核
- 逐条列"约束—验证方式—是否满足"表 + 验证代码（2021 FAST 题官方示范）
- 按实际意义校验：2024 C 官方判卷点——方案是否满足种植面积/不重茬/涝害约束、年利润与总利润是否一致、田间管理是否便利

## 2. 分题型验证重点（官方评阅信号）

| 题型 | 验证重点 |
|---|---|
| A 连续机理 | 对照参考数值量级；约束逐条核验；"用数值论证，而非仅仅算出"（2024 A）；仿真要说明设计与有效性 |
| B 离散/统计 | 定义自洽；理论分析与仿真**两条路都要有具体过程并明确呈现结果**（2024 B）；抽样误差对决策的影响（2024 B 问题 4） |
| C 数据决策 | 结果按实际意义校验；收益-风险权衡的稳健性；方案可行性与经济影响评估（2023 C 问题 4） |
| D/E | 置信区间 + 偏离讨论；算法全局最优性讨论；方案期望损失的统计显著性（2023 D） |

## 3. 执行节奏

- **Codex** 实现验证脚本（与求解脚本同目录，命名 `verify_*.py`），Qoder 审查
- 验证**与求解并行**：每出一版结果立刻跑四件套，不要堆到最后 6 小时
- 验证发现的模型缺陷 → 回炉 Skill 02（这正是备选模型存在的意义）

## 4. 常见错误
1. **走过场灵敏度**：只扰动一个无关紧要的参数，或扰动了却不讨论结论变化
2. **只报好不报坏**：回避误差与失败案例——评委最反感"虚拟化"（总则原文）
3. **在线优化用了未来信息**：实时/滚动决策里用了全期数据（2021 D 明令禁止）
4. **验证与正文脱节**：验证写在附录但正文结论不引用，等于没做
