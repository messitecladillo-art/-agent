# 范文模式挖掘

范文是结构观察集，不是当前题目的答案、官方规则或获奖保证。本技能先盲读目标论文，
再用评阅信号审查，最后只把抽象模式写入 pattern card。

## 输入

- 已锁定赛事/届次/题型；
- 目标论文或算法分类索引；
- 对应官方评阅文件；
- 研究问题：摘要、模型链、验证、图表或排版中的哪一类模式。

## 输出

一份 exemplar-pattern-card：

- source_ref、文件哈希、页码/章节范围、抽取置信度；
- observation（可定位事实）；
- generalized_rule（跨题型可迁移的规则）；
- boundary（不能迁移的背景/数字/格式）；
- review_test（如何验证当前题目是否适用）；
- 至少一条反例或短板；
- copyright_status 和不复制声明。

## 精析维度

1. 摘要是否按小问覆盖目标、方法、关键结果和边界；
2. 题面如何转成问题树，章节是否与小问/模型对应；
3. 变量、假设、坐标、单位、边界和参数是否先定义；
4. 模型链的输入—中间量—输出—算法—判据；
5. 数据预处理、异常/缺失、时间效应和切分；
6. 结果是否翻译成题目要求的方案；
7. 误差、敏感性、基线、守恒/可行性和独立检验；
8. 图表密度、caption、三线表、公式编号、代码附录和篇幅；
9. 按 review rubric 找到的缺口。

## 抽取纪律

- 先记录“看到什么”，再写“可以怎样抽象”；
- 单篇论文支持的是该论文采用了某种做法，不支持该做法必然有效；
- 不保存长段原文、完整公式、原图、代码、参数、地理信息和结论；
- 参考论文的字体/字号/页数/章节名不能升级为官方要求；
- 文本抽取乱码时降低置信度，以渲染页或源文件复核。

## 比较方法

按同一题型或同一算法选两篇以上，比较：

- 共同结构；
- 题面特化差异；
- 验证互补性；
- 复杂度与可复现性；
- 哪些“看起来高级”的部分没有证据。

## 硬门

- 没有官方/题面对照：只能输出观察，不能写规则；
- 想直接改写范文答案：拒绝并改为抽象模式；
- 把论文奖项当方法效果证据：BLOCKED；
- 未记录版权边界或 source_ref：不进入知识库。
