# 参考论文模式卡：只提炼结构，不复制内容

## 来源登记

- 来源类型：用户提供的数学建模校赛论文 PDF（本地只读分析）
- 文件指纹：`sha256:6e330b3520ce57b4fa9de3674e3dead4eef7bcf0fcc20ad08af1264f3ba48eae`
- 版面观察：41 页、A4、XeTeX 输出；页码/版式以渲染页为准
- 证据记录：`PAPER-SKILL-2026-0901-001` 的 Explorer/Critic 报告（项目运行证据，不是论文正文）

本卡记录的是“看到什么—可以怎样抽象—哪里不能照搬”。它不保存原 PDF、整段原文、
原图、完整公式或代码。任何要写入正式论文的数字、参数、结论和格式要求，都必须
重新回到当前题面、官方规则或可复现结果核验。

## 模式观察与抽象

| 页段 | 观察到的结构模式 | 可迁移写作规则 | 明确排除的特例 |
|---|---|---|---|
| 1 | 标题、摘要、关键词集中呈现；摘要按小问推进并给出方法/结果 | 摘要应覆盖每个交付物，方法与数字绑定 claim；最后单独写边界/特色 | 标题措辞、摘要句子和具体数值 |
| 2–3 | 先重述题面，再按小问说明建模路线 | 每个小问建立 `question → output → model role` 映射，避免先写模型名 | 章节编号和本题的地理背景 |
| 3–5 | 假设独立列出，符号表有“符号—含义—单位”，跨页重复表头 | 首次使用即定义语义、方向、单位、粒度和来源；符号表可分页但表头不丢 | 具体符号、参数值、表格列宽 |
| 6–14 | 控制关系、参数化、初/边界条件、离散、稳定性和判据分节；公式编号可回链 | 保留“定义/方程 → 中间推导 → 算法接口 → 输出判据”链；公式用语义 label | 具体物理方程、连续编号策略和数值方案 |
| 15–17 | 敏感性表格后有趋势、幅度、稳健区间与异常点解释 | 图表必须支撑已登记 claim，正文说明范围和不能推出的结论 | 本题的时间区间和临界阈值 |
| 18–27 | 多层/多情景模型先共享方程，再做因素开关和无量纲比较 | 情景消融要写清“关闭了什么、保持了什么、比较的输出是什么”；无量纲化保留尺度选择和中间步 | 河口/潮汐/密度差等题面特例 |
| 27–29 | 先评价与推广，再列可定位的参考文献 | 优缺点对应假设和验证；参考文献字段完整且正文有引用 | 文献清单、DOI、推广结论 |
| 30–41 | 附录代码等宽、行号、按问题/情景分段；正文先讲算法 | 代码是正文推导的可回放实现，绑定入口、参数、种子、输出与版本 | 原代码、变量值、配色和截图 |

## 从模式卡到可执行规则

将上表转成四类字段，便于工作流和审计器使用：

```yaml
pattern:
  source_ref: reference-paper-pattern-card#<row>
  observation: <只写可定位的版式/结构事实>
  generalized_rule: <与题型无关的写作或排版规则>
  boundary: <不可迁移或需要官方确认的部分>
  class: layout_rule | reasoning_rule | validation_gate | provenance_rule
```

至少应产生以下门：

1. **题面覆盖门**：每个小问都映射到一个结果 claim，不能只保留范文的章节标题。
2. **符号门**：符号、方向、单位、粒度和来源先登记再使用；同一符号不能换义。
3. **方程门**：关键公式有唯一语义 ID、输入/输出、适用域、前置假设和验证。
4. **接口门**：连续模型、离散算法、代码参数和输出图表的变量/单位一致。
5. **交叉引用门**：每个图、表、公式、算法和附录有唯一 label、caption 和正文引用。
6. **验证门**：按题型安排互补检查；单张漂亮图或训练集指标不能充当验证。
7. **渲染门**：干净环境检查缺字、公式溢出、浮动体遮挡、表头续页、代码裁切和灰度可读性。
8. **原创性门**：只模仿结构和表达机制，不复制范文文字、图、代码或答案。

## 证据强度与使用限制

- 这是一篇单一范例的结构观察，能支持“该范例采用了某种组织方式”，不能支持“该方式
  必然提高奖项概率”。
- PDF 没有提供源 TeX；无法从 PDF 证明原作者使用的宏包、宏名或可编辑源结构。
- 文本抽取存在 CJK 字体映射告警；字体、间距和断页应以渲染页/源文件复核，不以乱码文本
  推断数学符号。
- 官方竞赛格式优先级高于本卡；若届次、组别或赛区不同，样式和页数必须重新锁定。
