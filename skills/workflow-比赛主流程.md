# Workflow · 比赛主流程（72 小时作战脚本）

> 适用：国赛（约 68 小时，周四 18:00 – 周日 20:00 提交）；美赛（约 100 小时）按同构拉长。
> 规则：每个阶段出口都有**评审门**，产出不过门不进下一阶段；所有产出落盘（守则红线）。
> 战时特例：比赛期间分支评审可简化为"Qoder 快审"，但**评审动作本身不可省**。

## 阶段 0 · 审题破题（0 – 2 小时）

| 项 | 内容 |
|---|---|
| 主责 / 辅助 | Qoder 主导 / 全员读题 |
| 用哪个 skill | **Skill 01 审题破题** |
| 产出 | 审题报告 → `notes/problem-analysis.md`；国赛含选题决定 |
| 评审门 | 全员对子问题清单无异议；评审预期清单已抄出 |
| 红线 | 2 小时内必须定题；超时按"最熟题型"强制定题 |

## 阶段 1 · 建模（2 – 10 小时）

| 项 | 内容 |
|---|---|
| 主责 / 辅助 | Qoder 主建 / Codex 代码化辅助 |
| 用哪个 skill | **Skill 02 模型选型与建模** |
| 产出 | 模型决策记录 → `models/README.md`（每子问题 1 主 1 备 + 灵敏度预案） |
| 评审门 | 每个自定义量都有定义与论证；假设清单无空话 |
| 并行 | **写作同步启动**：Qoder 先写问题分析/假设/符号/框架骨架（约占全文 30%） |

## 阶段 2 · 求解（10 – 40 小时，与阶段 3 交错）

| 项 | 内容 |
|---|---|
| 主责 | Codex（分支 `task/`，实验记 `experiments/log.md`） |
| 用哪个 skill | **Skill 03 求解与实现** |
| 产出 | 代码 → `models/`；数值结果表 → `experiments/`；干净数据 → `data/processed/` |
| 评审门 | 关键数值已对表（A 题）/ 约束逐条验证表已成 |
| 卡壳预案 | 单点卡 30 分钟 → 记录阻塞、切备选模型，不静默空转 |

## 阶段 3 · 验证与灵敏度（与阶段 2 交错，最迟 40 – 52 小时完成）

| 项 | 内容 |
|---|---|
| 主责 / 审查 | Codex 实现 / Qoder 审查 |
| 用哪个 skill | **Skill 04 验证与灵敏度分析** |
| 产出 | 验证四件套记录 → `experiments/log.md` |
| 评审门 | 灵敏度 ≥2 参数且有结论讨论；置信区间/误差指标齐 |

## 阶段 4 · 写作与图表（骨架同步，52 – 64 小时收稿）

| 项 | 内容 |
|---|---|
| 主责 / 辅助 | Qoder 主笔 / Antigravity 出图到 `paper/figures/` / Codex 理附录 |
| 用哪个 skill | **Skill 05 论文写作** |
| 产出 | 完整论文 → `paper/` |
| 评审门 | 每个子问题有明确数值答案；图表四要素齐；数值全文一致 |

## 阶段 5 · 终检与提交（最后 6 – 8 小时）

| 项 | 内容 |
|---|---|
| 主责 | Claude API（`scripts/agents/review.py`）+ Qoder 终审 |
| 用哪个 skill | **Skill 06 论文评审与终检** |
| 流程 | ① 冻结模型 → ② review.py 全文一轮 → ③ rubric 四遍人工终审 → ④ 阻塞项修复复审 → ⑤ 摘要最后精修 → ⑥ 提交 |
| 红线 | 最后 2 小时只许做格式与摘要，不许动模型与数值 |

**提交踩坑清单（经验谈血泪项，逐项打勾）**
- [ ] 美赛：交卷前电脑时间调为**美东时间**，否则系统误判晚交
- [ ] 美赛：报名系统 first name = 名 / last name = 姓，别填反
- [ ] 美赛：提交 PDF；页数上限按当年题目（20 或 25 页）
- [ ] 赛中**禁止与队外任何人讨论**——官方监控论坛与群
- [ ] Word 公式多易死机：全程勤按 Ctrl+S，且 `paper/` 每 2 小时 git 提交一版
- [ ] 摘要与正文数值最后对一遍表（评委抽查高频点）

## 赛后（提交后 1 周内）

1. 官方评阅要点公布 → 用 Skill 06 rubric 自评，差距写入 `notes/`
2. 全流程复盘：哪次评审门拦下了真问题、哪个环节超时 → 更新本 workflow 与对应 skill
3. 论文与代码归档打 tag：`contest/<年份>`
