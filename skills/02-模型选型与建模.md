# Skill 02 · 模型选型与建模（阶段 1：建模）

> 目标：为每个子问题选定**主模型 + 备选模型**，并给出完整建模推导。
> 核心判据（官方总则 2021/2023 原文提炼）：**鼓励针对具体问题的自主创新，反对对模型/算法的简单套用**；
> **贴合题目的简单完整模型，优于炫技的复杂模型**（breakdown §5-2）。

## 2. 选型决策树

1. 子问题类型是什么？（分析/预测/优化/评价/机理）
2. 有没有数据？数据量级与质量？
   - 无数据/少数据 → 机理模型、灰色、仿真优先
   - 大数据 → 机器学习，但**必须配可解释性讨论与误差指标**（MAE/RMSE/R²）
3. **能精确求解就不要上启发式**（规划可解 → 不用 GA）；用了启发式必须讨论收敛性与全局最优性（2023 D 评阅要点：算法能否保证全局最优是评审点），并**通过对更多实例的测试说明算法有效性**（2020 B 原文）
4. 复杂度必要性自问：删掉这个模块结论会变吗？不会 → 删
5. 每个子问题定 **1 主 + 1 备**，主备之间最好可互验

## 3. 建模铁律（官方评阅信号）

1. **模型 > 算法 > 数值**（2021 D 原文：模型建立成功即使算法未完全给出也可认为有效；纯数值计算不构成好论文）
2. **定义即得分点**：题目未定义的量（覆盖率、相似度、风险指标）→ 先定义、再论证、再使用（2023 B：坡面覆盖率必须自定义并论证；2024 B：决策判据与量化指标必须明确）
3. **统计假设不能默认**："不作正态性假设而直接使用正态分布是不允许的"（2024 B 原文）；小样本用精确分布（几何/超几何），大样本用近似要说明理由
4. **耦合关系是加分点**：2023 C 官方注——同时求解补货与定价的耦合关系"是有价值的"；预测未知时从成本效益出发
5. **不确定性必须建模**：决策题给置信区间（2023 D）、讨论偏离合理范围的影响、收益-风险权衡（2024 C）
6. **每条假设对应一个模型简化**，与后文一一对应；空泛假设是扣分点（breakdown §2）
7. **针对问题结构设计，不套现成骨架**：照搬文献两/三段式不接受（2014A）；仅用通用模型 + 所有参数一起优化"一般不可能精准标定"（2017A）；不应使用现成算法，要针对问题结构设计（2017D）；通用启发式/仿真直接套不可接受（2018B）
8. **先拿基本分再冲档次**：评阅常按分档机制——如 2006A 目标函数须含三要素（销售额表达式/竞争力系数/计划准确性因子），**达到要素即给基本分值**，深化模型才提档次。建模时先保证要素齐全

## 4. 灵敏度分析预设计（建模时就要定，别等写完补）

- 至少锁定 **2 个关键参数**（提交前清单硬性要求）
- 扰动范围、扰动方式（单参数/联合）、观察量，写进模型决策记录
- 2023 D 要求：讨论参数偏离合理范围对结果的影响——这就是灵敏度分析的官方说法

## 5. 输出模板（模型决策记录）

```markdown
# 模型决策记录：子问题 <编号>
- 子问题陈述（原题引用）
- 选型：主模型 / 备选 / 理由 / 放弃方案及原因
- 自定义量：定义 + 论证
- 假设清单（编号，逐条对应简化作用）
- 核心公式与推导要点
- 输入输出：数据来源 → 结果形态
- 灵敏度预案：参数 ×、y，扰动 ±%，观察 <指标>
- 验证预案：对表值 / 特例 / 与备选模型互验
```

## 常见错误
1. **算法堆砌**：三种优化算法并列跑一遍取最好的——官方点名"套用式使用"
2. **大材小用**：简单回归可解却上深度学习，且无可解释性讨论
3. **定义缺失**：直接使用"覆盖率""风险"而不定义（B/C 题重灾区）
4. **假设套话**："假设数据真实可靠"这类零信息假设写满一页
5. **综合评价法滥用**：对有明确机理/成本结构的决策问题（如排队返程选择、信贷决策）简单主观地套加权综合评价——官方两次点名"不是一个好的做法"（2019 C、2020 C）；综合评价只适合多属性比较排序场景
6. **忽略本题特殊因素**：未考虑题目特有情境的通用模型"对本问题的价值不大"（2016 B：无信号路口、车速差异等）
