# 题面与赛事范围锁定

本技能把“我以为题目要求什么”变成可引用的 problem_contract。它优先读取用户提供的
原始题面和当届通知，不用范文或旧模板代替规则。

## 输入

- 原始题目 PDF/DOCX/网页快照及全部附件；
- 赛事名称、届次、组别、赛区和阶段；
- 当届竞赛通知、参赛规则、格式/页数/匿名要求；
- 用户要求的目标产物和截止时间。

## 输出

生成 problem-contract/v2：

- contest、edition、group、region、problem_id；
- statement_refs（页码/段落/附件和摘要哈希）；
- 每个小问的原句、目标动词、输出量/方案和硬约束；
- official_format profile 及 status；
- 可见信息边界（offline/online、允许的时间窗）；
- 未决问题和不可安全假设的字段。

## 操作顺序

1. 先复制/哈希原始输入到只读输入清单，确认附件完整、编码和页数；
2. 阅读全文，不先看范文答案；逐句标记确定、分析、预测、评价、优化、设计、讨论等
   任务动词；
3. 将题面数字、单位、时间范围、对象集合和“注”段逐一登记；
4. 区分硬约束、软目标、背景信息、示例和开放问题；
5. 确认是否允许使用未来信息、外部数据、联网、队外讨论或附加假设；
6. 读取对应赛事 profile。若规则来自旧届或课程模板，标 OFFICIAL_PENDING；
7. 由 Owner 复核题号/附件/格式范围后冻结 revision。

## 题型初筛（只产生候选）

使用题面结构而不是单个关键词：

- 连续机理：状态/守恒/几何/边界/微分关系；
- 离散优化：整数、路径、排班、切割、容量和顺序；
- 数据决策：表格、时间戳、标签、成本、需求和不确定性；
- 仿真/随机：到达、服务、个体规则、情景和重复；
- 政策/开放：多目标、利益相关者、可行性和边界。

初筛结果写 CANDIDATE/HYPOTHESIS，并保留至少一个替代题型，交给 model-routing。

## 硬门

- 没有原始题面或附件清单：BLOCKED；
- 小问编号与题面不一致：BLOCKED；
- 每个小问没有明确 deliverables：BLOCKED；
- 官方格式未确认却声称“符合提交要求”：OFFICIAL_PENDING；
- 在线题的可见信息边界未写：不得进入求解；
- 题面与资料/范文冲突：保留冲突并请求 Owner，不选“看起来更合理”的一方。

## 质量检查

- [ ] 原句可由 source_ref 定位；
- [ ] 每个动词有对应输出；
- [ ] 数字和单位没有从附件摘要手抄；
- [ ] 题面约束与团队偏好分列；
- [ ] 当前 profile 与旧模板分列；
- [ ] 版本/组别/赛区/阶段已冻结。
